## Music_sort
##### Небольшая программа для сортировки музыки по папкам
Основные функции
- Вывод информации о треках
- Сортировка по папкам исполнителей
- Переименование в формат Название-Исполнитель

#### Использование
```
music_sort.py [-h] [-i INPUT_DIR] [-o OUTPUT_DIR] [-s] [-r]

По умолчанию выводит информацию о всех треках в указаной папке

-h, --help            show this help message and exit
  -i INPUT_DIR, --input-dir INPUT_DIR
                        Путь к директории для сканирования (по умолчанию: текущая директория).
  -o OUTPUT_DIR, --output-dir OUTPUT_DIR
                        Базовая директория, куда будут перемещены треки в папки исполнителей. Если не указана, используется --input-dir.
  -s, --sort            Сортировка треков по папкам исполнителей.
  -r, --rename          Переименование файлов в формате название-исполнитель
```
